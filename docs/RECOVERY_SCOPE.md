# Archive scope

Includes EXP001–EXP015 source, settings, saved results and audit/freeze records.

Original report manuscripts, third-party reference notebooks and a copied paper illustration were omitted. Experiment CSVs, source, evaluation plots and output logs were retained.

`provenance/` contains original recovery metadata, restored-artifact paths, checksums and a list of publication edits. These are source records, not new experiment results. Some historical manifests still refer to files held only in the original private archives.

To check the **public release files**, run `python tools/verify_archive.py`. Do not assume historical nested archive seals have been regenerated.
